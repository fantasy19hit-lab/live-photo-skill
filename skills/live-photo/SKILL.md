# 实况图 / Live 图

交付一个以 `_MP.jpg` 结尾的文件。使用本 skill 自带脚本和固定 XMP 模板，将已有配图和视频合成为实况图，不限定使用或发布平台。历史样片已有用户实测记录；新文件的本机校验不等于重新做过手机或应用验证。

## 合成

需要 Python 3.9+、FFmpeg（含 ffprobe、libx265），无 Python 第三方依赖、无需账号或网络。复用本机环境。把下列 `<skill目录>` 替换为**当前读取的 SKILL.md 所在目录**；不要寻找旧实验目录或修改脚本来填写素材路径。

```bash
python3 "<skill目录>/scripts/live_photo.py" build \
  --image "/绝对路径/封面.png" \
  --video "/绝对路径/视频.mp4" \
  --output "/绝对路径/作品_MP.jpg"
```

- 输入图可以独立于视频，不必截帧。普通 JPEG 保留压缩像素，去掉旧 XMP；PNG 等格式转 JPEG。默认保留完整视频，不擅自截取内容；用户指定片段时加 `--start 秒 --duration 秒`。
- 视频自动处理：符合条件的 HEVC/hvc1 MP4 原样嵌入，其余转 HEVC、8-bit 4:2:0、30fps、最长边不超过 1920、音频 AAC（如有）。默认不补音轨。原素材保持不变。
- 输出名必须以 `_MP.jpg` 结尾；使用新文件名，脚本拒绝覆盖。结果旁自动生成 `.jpg.json` 校验报告。
- 要求进程退出码为 0 且报告 `status` 为 `passed`。脚本已检查 XMP、视频偏移和长度、完整图片和视频解码，正常构建不必重复 verify。

## 校验已有文件

```bash
python3 "<skill目录>/scripts/live_photo.py" verify "/绝对路径/作品_MP.jpg"
```

该命令校验**本 skill 的固定格式**，不是所有品牌动态照片的通用鉴定器。失败时根据实际错误修复；不要把普通 JPG、GIF、MP4 或图片视频 ZIP 作为成功实况图交付。遇到 MPF/HDR 多图 JPEG，先导出普通 SDR 图片；不要直接移动其内部偏移。

## 交付

提供实况 JPG 的绝对路径链接，说明按**原文件**传输，避免聊天软件压缩或另存静态图。报告可作为附带文件，无须让用户一起上传。按用户指定的使用场景交付；未指定平台时无需追问平台。系统相册与目标应用可能采用不同识别方式，应以目标场景的实际结果为准。手机端结果由实际测试确认，不把历史成功扩展为所有机型或应用版本保证。

仅在维护格式或排查兼容性时读 [来源与实测边界](references/provenance.md)。不要回退到只有 MicroVideo 四个字段的旧方案，也不默认交付 Apple 的 JPG+MOV 双文件包。
